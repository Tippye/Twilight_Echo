# QQ 音乐 Windows 接入

使用方法、版本要求、测试与统一打包命令见 [QQ 音乐插件说明](../integrations/qqmusic/README.md)。宿主播放接口见[音频引擎 API](audio-engine-api.md)。

## 功能分工

- QQ 插件负责官方扫码登录、会话、曲库数据、歌曲身份、音质选择和授权媒体取流。
- 本地音频代理负责内容解密、Range、有限并行预读和租约内缓存。
- 宿主负责标准媒体解码、设备输出、播放进度与暂停状态，并展示当前实际音频参数。
- 首选音质不可用时，在同一歌曲内有限降级；不替换歌曲记录，保留首选设置。

## 版本与发布

QQ 插件源码和回归测试位于主仓库 `integrations/qqmusic`。构建主程序后运行 `pnpm run prepare:qqmusic-release`，将安装包、插件、版本清单和校验文件放在同一个 Release 中发布。

插件直接访问 QQ 官方服务，不要求安装或运行原版 QQ 音乐。歌曲与音质仍受当前账号授权限制。本地臻品处理组件不在此实现范围内。

杜比媒体解码与空间扬声器输出分别处理；DTS/5.1 正向样本、空间输出及增强逐字歌词需要单独验证。仓库不携带账号、令牌、运行 profile、真实媒体地址或音频缓存。
