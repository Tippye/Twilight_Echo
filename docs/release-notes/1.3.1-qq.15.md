# Twilight Echo 1.3.1-qq.15

- 优化 FLAC 和 Hi-Res 音频定位，减少拖动进度和切换音质时的重复读取与超时。
- 优化取流、预读与分块缓存复用，减少重复下载；取消旧读取时保留仍然有效的音源缓存。
- 修复音质切换或停止播放时意外跳到下一首的问题。
- 切换音质时保留当前歌曲、播放进度和播放／暂停状态，暂停后切换音质不会自动开始播放。
- 不可用音质在同一首歌曲内自动降级，保留首选设置，避免反复换曲重试。
- 修复切换音质失败时重复弹出错误提示的问题。
- 修复 HiFi 控制台与当前音频源不同步的问题，展示实际格式、采样率、位深、码率、声道和文件大小；参数缺失时显示未知。
- 移除 QQ 本地臻品处理组件及相关入口，保留普通网络音源和逐曲音质选择。
