# 1.3.1-qq.5

QQ 音乐 Windows 插件升级至 `0.4.0-rc.6`。播放条提供九档首选音质，切换保留当前歌曲、进度和暂停状态；缺少对应音源时在同一记录内有限降级。臻品母带和臻品全景声使用歌曲实际候选，臻品音质明确标为本地音效。

高码率媒体代理采用有界并行 Range，宿主为已确认有限时长的高采样率 HTTP PCM 复用现有缓冲区预缓冲。实机《One Last Kiss》96 kHz/24-bit 的最终一分钟观察中，60.78 秒推进60.47秒，没有反复加载。该结果不代表所有网络环境，也没有证据确认 QQ P2P 加速。

喜欢按钮读取真实状态并支持收藏/取消收藏。HiFi、播放条与可视化统一展示当前音源的实际大小、编码、采样率、位深和源声道，源声道与输出声道分别显示。

本地臻品音效使用独立 x86 工作进程，在重采样到设备格式前处理受支持的普通立体声 PCM。需要本机已安装并匹配固定摘要的 Windows QQ 音乐22.71组件及服务端有效能力；发布包不含 QQ DLL、模型、账号或音频。组件、能力或格式无法验证时不会宣称音效已启用。原生异常、注销和插件撤销会终止对应授权，公共队列数据不暴露工作进程参数。

安装此宿主后，在扩展中心安装配套 `.tep`，使用官方 QQ 扫码登录。现有任务客户端已更新，保持独立 profile；安装包不会携带该 profile。

验证与边界见 [Task13 记录](../qqmusic-research/task13/README.md)。真实 DTS/5.1 正向音源、Atmos 空间输出、增强逐字歌词仍未验证。并行打包和原生压力测试期间曾出现一次播放超时，冷启动后的同路径复验通过；未将该历史失败改写为成功，也不承诺极端系统负载下的延迟。
