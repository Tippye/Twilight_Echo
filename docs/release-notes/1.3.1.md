# Twilight Echo v1.3.1

_界面退场，音乐继续。_

1.3.1 在 1.3.0 的基础上加入余晖模式、全窗口插件体验与灵动岛，并完善快捷键、页面历史、网络音乐源和原生音频稳定性。此前 1.3.1-preview 中的修复已全部包含在正式版中。

> [!NOTE]
> **对比范围：1.3.0 → 1.3.1 正式版。** 本说明以 **1.3.0 正式版** 为对比基线，包含 1.3.1-preview 的修复与预览期之后合入的改动。

## 本次更新重点

- **余晖模式（Afterglow）**：卸载全部界面渲染器释放内存，由原生音频引擎继续播放；托盘、媒体键、系统媒体控制和局域网遥控仍可操作，随时恢复界面且不中断播放。
- **全窗口插件体验**：插件 API v4 与 bridge v2 预览，插件可以在宿主窗口内提供完整的音乐工作区；Rhine 0.2.1 作为本地预览示例。
- **灵动岛**：宿主拥有的置顶 overlay 窗口，支持跟随主窗口、歌词显示、播放控制和 DIY 配置。
- **可配置快捷键与页面历史**：应用内快捷键可查看占用状态并自定义；鼠标侧键可以在页面历史中前进和后退。
- **网络音乐源与在线内容**：改进 WebDAV 浏览、认证和传输，补齐 FTP／SFTP／SMB／NFS／DLNA 行为；在线歌单支持分组与分页，网易云专辑增加发行筛选与标识。
- **原生音频与诊断**：继续完善 ASIO 设备协商、缓冲与 Native DSD 边界；诊断日志可跨进程持久化，并可恢复卡住的音频服务。
- **性能与内存**：歌曲列表虚拟化与顺滑回到顶部，限制壁纸、封面和主题素材的图片内存，降低长时间使用后的内存占用。

## 新增与扩展功能

### 1. 余晖模式（Afterglow）

_把界面收起来，让音乐留在后台。_

- 设置 → **系统与关于 → 运行与性能 → 余晖模式（Afterglow）** 可以立即进入，或选择在最小化／隐藏到托盘时自动进入。
- 进入后渲染器完全卸载，主进程、原生音频服务和（启用时的）GPU 进程继续运行。
- 恢复方式包括托盘菜单、单击／双击托盘图标、`Ctrl/⌘+Shift+E`（冲突时自动回退备用组合）、再次启动应用、Windows 任务栏图标和 macOS Dock。
- 恢复时渲染器采纳引擎的实时队列、曲目、进度、播放态、音量和倍速，不会重新加载队列，也不会打断正在播放的音频。
- 卸载期间仍可使用托盘传输控制、全局快捷键与媒体键、Windows SMTC、局域网遥控、Discord 状态和睡眠定时器。
- 只有原生引擎已完整接管且音源可继续播放时才会进入；流媒体 URL 通过原生队列热更新在后台续接，失败或队列播完会自动恢复界面，不会留下不可见的停止播放器。
- 详细条件、限制与实现位置见 [`docs/afterglow-mode.md`](../afterglow-mode.md)。

### 2. 全窗口插件体验与灵动岛

_插件不再只是侧栏里的一个页面。_

- 插件 API v4 新增 `ui` 类型与 `contributes.experiences`，通过受限的 `plugin-ui://` 协议、CSP 和 iframe 沙箱承载。
- bridge v2 使用一次性 MessagePort 与白名单操作，覆盖曲库读写、播放控制与观察、私有偏好、窗口退出／全屏等能力。
- 插件打开、关闭或替换体验视图不会隐式停止宿主播放；封面等本地资源通过受控句柄访问。
- Rhine 0.2.1 预览展示完整的曲库、队列、歌单、音频／EQ、DSP、下载和设置工作区；托盘、迷你播放器和桌面歌词可使用 Rhine 皮肤。
- 灵动岛通过 `twilight.overlay` 由插件配置，宿主负责窗口生命周期、几何、原生圆角裁剪和配置校验；歌词走独立通道，避免重复序列化。
- 详见 [`docs/plugin-experiences.md`](../plugin-experiences.md) 与 [`docs/dynamic-island.md`](../dynamic-island.md)。

### 3. 快捷键、页面历史与导航

- 应用内快捷键集中配置，并显示注册结果和占用状态，冲突时不再静默失败。
- Windows／Linux 鼠标侧键通过窗口 `app-command` 转发到渲染器的页面历史栈，并对重复投递去重。
- 页面历史与前进／后退状态和现有页面恢复逻辑统一，重启后仍能回到上次浏览位置。
- 在线歌单、专辑和艺术家详情页的返回操作统一到标题栏，修复详情页顶部被标题栏遮挡和空白占位问题。

### 4. 网络音乐源与在线内容

- WebDAV 修复端口推断、空密码认证、Digest 失败提示、路径编码、封面缓存标识和重定向安全，并补充行为与限制文档。
- 完善 FTP／SFTP／SMB／NFS／DLNA 的网络源配置、路径校验和元数据缓存。
- 在线歌单支持分组与分页加载，减少长歌单的整页等待。
- 网易云专辑增加发行日期筛选和 Explicit 标识；相邻曲目的播放地址准备更稳定。
- 插件可以通过 `twilight.library` 把歌单导入本地曲库，启动时的导入会排队并按批次原子应用。

## 改进与修复

### 5. 原生音频与诊断

- ASIO 改进驱动初始化窗口、采样率确认、缓冲候选重试和通道格式确认，覆盖更多大小端与有效位 PCM 格式。
- 修复调整 ASIO 缓冲或起始输出通道后未完整重开输出的问题，并在失败时尝试恢复原配置与播放状态。
- 修正 Native DSD 缓冲容量判断、NER8 数据展开和写入边界检查；检查 DoP 载波要求，避免把降低精度的 PCM 输出误报为 bit-perfect。
- 修复暂停淡出与独占设备释放的超时处理；单个控制命令失败不再连带清除其他等待中的请求。
- 修复音频服务就绪恢复与启动 DSP 配置之间的竞争。
- 诊断日志跨进程持久化，支持故障标记、时间线和卡住音频服务的恢复流程。

### 6. 性能与内存

- 歌曲列表窗口化渲染，滚动和回到顶部更顺滑，大数据量下列表切换更稳定。
- 限制壁纸解码尺寸和图片缓存上限，释放主题预热、主题工坊尺寸探测和临时图片解码占用的内存。
- 降低封面重复分配和光栅化开销，长时间浏览后内存增长更可控。
- AutoMix 分轨包改为流式读取 LZMA ZIP，并使用固定版本离线解码器；CPU／CUDA 分轨包按发布规则校验后打包。

### 7. 界面与播放修复

- 修复播放页「文字明暗 → 跟随主题」在自定义／继承背景下未生效的问题，保留手动文字明暗与歌词颜色。
- 修复播放页左上角返回、菜单、头像区域与背景颜色不一致的异常色块。
- 修复全局浅色背景使深色播放页出现白色窗口外框的问题。
- 统一毛玻璃／窗口外框与沉浸播放页的视觉过渡，清理详情页顶部空白占位。
- 修复侧栏页面管理启用或恢复页面后入口仍被折叠分组隐藏的问题，保存后展开分组并滚动到新增入口。
- 改进桌面歌词设置的分组、标签和窄窗口布局。

## 升级说明

- 1.3.1 为 **稳定频道** 正式版，版本号不再带 `-preview` 后缀；已安装 1.3.1-preview 的用户可以直接覆盖升级。
- Windows 安装包仍未进行商业代码签名，可能出现 SmartScreen 提示；请从项目 GitHub Releases 下载，并使用随附的 `.sha256` 文件核对安装包。
- ASIO、Native DSD 和具体解码设备的实际兼容性仍取决于设备与驱动；本说明不宣称任何特定型号已完成真机验证。
- 余晖模式只卸载界面渲染器，不替代原生音频服务、主进程或 GPU 进程；卸载期间不提供喜欢按钮、心动模式、随机模式编辑、桌面歌词和迷你播放器窗口。
